STEP 1: Extract the zip file
   $ unzip verids-complete.zip
   $ cd verids-complete

STEP 2: Install dependencies (express, cors)
   $ npm install

STEP 3: Start the server
   $ npm start

   Output:
   🔍 VeriDS running on http://localhost:3000
   📝 Analysis engine ready for text and URL verification

Q: "Port 3000 already in use"
A: Kill the process: lsof -i :3000  (then kill <PID>)
   Or use a different port: PORT=3001 npm start

Q: "npm install fails"
A: Make sure Node.js 16+ is installed
   npm cache clean --force
   npm install

Q: "Page not loading at localhost:3000"
A: Check server is running:
   curl http://localhost:3000/api/health
   Should return: {"status":"ok","version":"1.0.0"}

Q: "Analysis returns error"
A: Check the error message - each error has a specific reason
   (network error, invalid URL, no article content found, etc.)
